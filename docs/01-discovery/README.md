# Episódio 1 — Discovery

A fase parte de cinco ideias de ferramenta, pontuadas numa matriz de decisão em que o diagnóstico de processos fica com 4,60.
Três reuniões simuladas moldam o produto: o sócio quer "um número só", a analista quer profundidade (por isso os campos são opcionais) e o dono da clínica impõe que dado de paciente não saia da máquina.
O fluxo atual (AS-IS) e o desejado (TO-BE) fecham a fase, junto com as perguntas-chave do roteiro.
